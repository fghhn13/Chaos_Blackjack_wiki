---
title: 术语表
---
| 术语 | 含义 |
| --- | --- |
| 资金 Bankroll | 你手里的筹码。 |
| 爆牌 Bust | 超过爆牌线（21，除非混沌规则改了它）。 |
| 混沌预算 Chaos budget | 混沌 AI 能花掉的效果次数，由难度档决定。 |
| 混沌规则 Chaos rule | 混沌 AI 为一局临时启用的规则改动。 |
| 加倍 Double | 下注翻倍，只拿一张牌，然后停牌。仅限第一次决策。 |
| 暗牌 Hole card | 庄家扣着的第二张牌。 |
| 天生 21 点 Natural | 头两张牌正好 21，赔率比普通赢更高。 |
| 平局 Push | 打平，退还下注。 |
| 补货 Restock | 商店换一批新货。 |
| 软牌 Soft hand | A 仍然按大的算的一手牌。 |
| 投降 Surrender | 放弃这手牌，拿回一半下注。仅限第一次决策。 |
