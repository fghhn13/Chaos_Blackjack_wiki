![J-54 立绘](../img/j54.png)

J-54 从不碰你的牌，它只改**它自己**的牌值，一次一条条件，再留给你一点算力去改造它发牌用的那副牌。这张牌桌什么都不卖，没有商店。

## 胜负

一局共 {{ fact: settings.mode.j54.rounds.value }} 回合，带着 {{ fact: settings.mode.j54.config.start_money.value }} 筹码和一副 52 张的牌开始。从第 {{ fact: settings.mode.j54.target_from_round.value }} 回合起，某回合结算时筹码达到起始的 {{ fact: settings.mode.j54.target_multiple.value }} 倍（即上方的目标）就获胜；或者**捕获小丑**（见下文）。破产，或第 {{ fact: settings.mode.j54.rounds.value }} 回合结算后仍未获胜，就算输。

整局使用同一副牌，每回合重新洗牌，被移除的牌不会回来。每次结算后 J-54 会往牌堆加入 {{ fact: settings.mode.j54.entropy.value }} 张小牌（2–6），所以放着不管，牌堆只会慢慢变差。

## J-54 的程序：条件与阵营

同一时间只有一条条件生效，每条持续 {{ fact: settings.mode.j54.segment_len.value }} 回合，在该段第一个回合的下注阶段开始，以牌桌事件公布，并在规则栏显示剩余回合和所属阵营。条件只改变 J-54 的牌值或它停牌的点数：

- **经典阵营**，和普通 21 点同向：{{ link: chaos_rules.j54_black_plus }}、{{ link: chaos_rules.j54_even_plus }}、{{ link: chaos_rules.j54_hearts_scale }}、{{ link: chaos_rules.j54_stand_19 }}。
- **反向阵营**，把普通 21 点的方向反过来，热度图会翻转：{{ link: chaos_rules.j54_stand_15 }}、{{ link: chaos_rules.j54_low_plus }}。
- **独立**，自成一类：{{ link: chaos_rules.j54_faces_set }}。

每条条件的最后一回合，J-54 会预告下一条的阵营。

## 算力与操作

每回合进入下注阶段时获得 {{ fact: settings.mode.j54.compute_income.value }} 点算力，最多存 {{ fact: settings.mode.j54.compute_cap.value }} 点。算力只能在下注阶段花在三种操作上：

**切牌**从你选定的一个点数加颜色的组里移除 {{ fact: settings.mode.j54.cut_size.value }} 张（每组旁边标着热度）；**热清除**在热度最高的 {{ fact: settings.mode.j54.hot_purge_candidates.value }} 个点数里随机抽一个，移除 {{ fact: settings.mode.j54.hot_purge_size.value }} 张，付费后才公布抽到哪个；**释放**把封存的小丑放进牌堆，整局一次。牌堆最少保留 {{ fact: settings.mode.j54.min_deck.value }} 张，被移除的牌在 Deck 和 Run 标签里可以看到。

## 热度图与仪表

牌堆条按热度上色：**绿色表示移除这个点数对你有利，红色表示应该留着**，颜色越深影响越大。热度的含义是每移除一张，你这手牌的胜率变化多少个百分点。下方的仪表显示这副牌每手的胜率，并标出下注档位（{{ fact: settings.mode.j54.bands.value }}：胜率 % : 建议下注占现金 %；低于第一档时建议最低注）。两者都已计入当前条件和你的固件，每次操作后立即更新。它们只指出**方向，不替你做计划**，建议注额也不会改变下注范围。

## 小丑：捕获

对你来说，小丑是一张软 A，永远不构成天然 21 点。从第 {{ fact: settings.mode.j54.capture_from_round.value }} 回合起，如果结算时小丑在你手里且这手牌没有输（赢、平或天然 21 都算，投降不算），就以捕获获胜；更早抽到或输掉这手，小丑会被洗回牌堆。J-54 抽到小丑时会改拿下一张，把小丑洗回去，并加入 {{ fact: settings.mode.j54.dealer_joker_penalty.value }} 张小牌。释放后，仪表会显示每手抽到小丑的概率。

## 样本悬赏

每条条件开始时，J-54 会点名它最看重的点数，也就是条件开始时热度图上最绿的那个点数。结算时你手里每有一张这个点数，就得 {{ fact: settings.mode.j54.bounty.value }} 筹码，输赢都给。

## 打法要点

- 每回合把算力花在最绿的那一组上，花完再看一眼：每次操作后热度图都会重算。算力存着不会生利息，而熵每回合都在往牌堆加小牌。
- 某一组明显领先时用切牌；前几名差不多时用热清除，同样的价格能移除更多牌，只是点数随机。
- J-54 预告下一条是反向阵营时，这一回合的算力先留着：热度图马上要翻转，现在切掉的牌可能正是之后想留的。
