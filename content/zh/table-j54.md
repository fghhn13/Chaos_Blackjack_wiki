核心主题：概率、计算、牌堆重构

J-54 是一台被设计成马戏团小丑的机械计算装置。它拥有极其夸张的表演动作与像素表情，却以冰冷、精确的程序语言与玩家交流。

与其他 Table 不同，J-54 不热衷于直接改变 Blackjack 的规则，而是修改构成赌局的 54 张扑克牌本身。

## 1. Table 核心机制

牌堆结构（Deck Structure）

本 Table 允许道具与混沌规则直接操作牌堆：

- 复制：增加指定点数或花色的牌。
- 剔除：从牌堆中移除部分牌。
- 重排：改变剩余牌的排列顺序。
- 回收：将弃牌重新投入牌堆。
- 扫描：获取剩余牌堆的统计信息。

部分效果可以持续多个回合，使牌堆逐渐偏离标准的 54 张结构。

## 2. 混沌规则示例

| 规则 | 效果 |
| --- | --- |
| 样本增殖 | 随机选择一个点数，复制其剩余牌 |
| 冗余清除 | 随机移除一种点数的部分剩余牌 |
| 分层排序 | 将高点数牌与低点数牌分组排列 |
| 数据回流 | 将部分弃牌重新洗入牌堆 |
| 分布偏置 | 改变指定点数在接下来若干张牌中的出现频率 |

## 3. 专属道具示例

| 道具 | 效果 |
| --- | --- |
| 样本复制器 | 将指定手牌的复制品加入牌堆 |
| 数据粉碎机 | 从剩余牌堆中删除指定点数的牌 |
| 分布扫描仪 | 查看剩余牌堆的点数分布 |
| 局部洗牌器 | 重新打乱剩余牌顺序 |
| 回收模块 | 将指定弃牌重新加入牌堆 |
