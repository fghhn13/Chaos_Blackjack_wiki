扑克头在购物与下注前公布持续或限时环境；当前正式方案让环境跨回合保留。最多同时存在 {{ fact: settings.mode.chaos.rule_slots.value }} 类，早期阶段使用较少位置。九类包括固定牌点、牌点增减、爆牌线、普通平局归属、庄家爆牌后果、收益封顶、道具封禁、商店涨价与玩家暗牌。每张卡片展示当前离线规则池的一个合法实例，不是固定脚本，实际对象、数值和期限以本局公布为准。

## 下注前只行动一次

开局核心选择完成后，离线荷官先进行本回合唯一一次环境决策，再开放购物、准备道具和下注。发牌后不追加变化；平静保留已有环境。每条规则公开对象、完整参数、剩余期限和解除方式。

限时规则在完整回合结束后计时，天然、平局与投降也推进；购物、查看与存档不推进。持续规则直到移除或替换。同类型最多一条，固定改写和增减属于不同类型。静默压制本回合效果，但存储规则仍占位、继续老化。

## 清除与冲突

条款撕除永久移除选中的一条环境规则；静默印章压制当轮全部环境，下回合恢复未到期者。已付价格和已结算收益不回滚。道具封禁会让下一件合法阶段使用的消耗品只被牺牲、无原效果，并解除封禁；若牺牲的是拆除或静默，也不会影响其他规则。

清除后整个类型冷却 {{ fact: settings.mode.chaos.director.cooldown_cleared.value }} 个后续准备阶段；自然到期冷却 {{ fact: settings.mode.chaos.director.cooldown_expired.value }} 个。AI 替换只让旧参数组合冷却 {{ fact: settings.mode.chaos.director.cooldown_replaced.value }} 个阶段。空位不当场补满。荷官仅替换符合条件的持续规则，限时规则等待到期，不靠换同参数续时间。

规则按对你的不利程度分为轻、中、重三级；重级规则（例如降低玩家爆牌线、庄家爆牌改判平局）从第 {{ fact: settings.mode.chaos.director.heavy_from.value }} 回合起才会出现，且同时最多一条，规则列表会标出每条的等级。玩家暗牌与道具封禁绝不共存；同场最多一条高压力规则。候选先过滤类型冲突、冷却、位置和压力预算。

## 算点、收益与信息

原始牌点 → 固定改写 → 增减 → 玩家永久商品效果 → 软 A → 整手识别 → 爆牌。天然按原始起手牌识别。收益封顶对手牌和理财到期正收益合计只处理一次，不截留本金、退款、贷款或回购，亏损与债务仍正常支付。涨价影响普通商品和当前未购库存，与采购折扣合并后一次取整。

玩家暗牌遮住第二张起手牌和精确总点，后来抽牌仍可见；终止行动、清除或静默后揭示。信息道具遵守各自范围，险情指针只给下一次要牌风险，不泄露隐藏精确点数。
