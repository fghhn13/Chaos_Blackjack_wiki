title: 混沌 AI
---
混沌 AI 从不直接碰牌。它只返回一小段结构化 JSON 动作，游戏先检查，再决定是否执行。

## 流程

1. 游戏为 AI 生成一份牌桌观察数据。
2. AI 用 JSON 回答：启用一条规则（带参数）、用掉玩家的一件道具，或者什么也不做。
3. **权限校验器**按当前难度档检查这个动作：允许的规则和道具、每回合动作数、混沌预算。
4. 通过的动作按名字在注册表里解析成规则修改器或道具使用；被拒绝的动作只会作为事件报告，不产生效果。
5. 模型出错或超时时，动作变成空操作，游戏照常进行。

## 离线替身与真实模型

没有 API key 时，AI 是一个确定性的离线替身；测试、CI 和 agent 接口默认都用它。接入真实模型后，每个混沌阶段发一次聊天请求，JSON 不合法时最多再发一次修复请求。
