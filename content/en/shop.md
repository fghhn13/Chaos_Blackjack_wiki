title: Table shop and money
---
The table shop uses run chips; the home [Shop](progression.html) uses tokens. Shops open before betting, and purchases must leave enough cash for the minimum bet.

Poker Head uses fixed base prices for goods, a limited permanent build and core-biased stock. See [builds, finance and replacement](poker-head-builds.html). Markup and discounts can change unpaid prices. Finance uses contract amounts; buyback refunds the actual price paid. J-54 *Experimental sells deck contracts, restocking every round. Classic items retain bankroll-percentage prices.
