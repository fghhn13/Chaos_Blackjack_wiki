---
title: Glossary
---
| Term | Meaning |
| --- | --- |
| Bankroll | Your chips. |
| Bust | Going over the bust limit (21 unless a chaos rule changes it). |
| Chaos budget | How many effects the Chaos AI may spend; set by the difficulty profile. |
| Chaos rule | A temporary rule change applied by the Chaos AI for one round. |
| Double | Double the bet, take exactly one card, stand. First decision only. |
| Hole card | The dealer's face-down second card. |
| Natural | A two-card 21. Pays better than a normal win. |
| Push | A tie: the bet is returned. |
| Restock | The shop rolls new offers. |
| Soft hand | A hand where an Ace still counts high. |
| Surrender | Give up the hand for half the bet back. First decision only. |
